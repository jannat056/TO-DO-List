## 💡 How It Works

The application allows users to create and manage a list of tasks.

When a user enters a task and submits it, JavaScript dynamically creates the task and displays it in the task list. Users can then mark tasks as completed or remove them from the list.

The project uses JavaScript DOM manipulation to update the interface without reloading the page.
